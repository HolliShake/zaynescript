# Standard Library
{: .no_toc }

ZayneScript ships six built-in modules accessible via the `core:` import prefix. Each module is loaded on demand — import only what you need.

## core:io — Input / Output

```javascript
import { print, println, scan, parseNum,
         format, clearScreen, setColor, decompile } from "core:io";
```

---

### print

**Signature:** `print(...args)`

Writes all arguments (space-separated) to stdout **without** a trailing newline. Accepts any number of arguments of any type.

```javascript
print("x =", 42); // x = 42  (no newline)
```

---

### println

**Signature:** `println(...args)`

Like `print` but appends a newline. Calling with no arguments prints a blank line.

```javascript
println("Hello", "World"); // Hello World
println();                 // (blank line)
```

---

### scan

**Signature:** `scan(prompt?: string) → string`

Reads one line from stdin and returns it as a string (newline stripped).  
If `prompt` is provided it is printed first without a trailing newline.  
Returns `null` on EOF.

```javascript
const name = scan("Enter your name: ");
println("Hello,", name);
```

---

### parseNum

**Signature:** `parseNum(str: string) → int | num`

Parses `str` into a number. Returns an `int` when the parsed value has no fractional part, otherwise a `num` (float).

```javascript
const n = parseNum(scan("Enter a number: "));
println(n * 2);
```

---

### format

**Signature:** `format(template: string, ...args) → string`

Returns a new string with each `{}` placeholder in `template` replaced by the next argument in order. Extra arguments are ignored; extra placeholders remain as-is.

```javascript
const msg = format("Hello, {}! You are {} years old.", "Alice", 30);
println(msg); // Hello, Alice! You are 30 years old.
```

---

### clearScreen

**Signature:** `clearScreen()`

Clears the terminal screen using ANSI escape codes.

```javascript
clearScreen();
```

---

### setColor

**Signature:** `setColor(fg?: int, bg?: int)`

Sets the terminal foreground (and optionally background) colour using ANSI colour codes.  
Calling with no arguments resets to default colours.

| Code | Colour |
|---|---|
| `30` | Black |
| `31` | Red |
| `32` | Green |
| `33` | Yellow |
| `34` | Blue |
| `35` | Magenta |
| `36` | Cyan |
| `37` | White |
| `0` | Reset |

```javascript
setColor(32);          // green text
println("Success!");
setColor();            // reset
```

---

### decompile

**Signature:** `decompile(fn: function) → string`

Decompiles a compiled user function back into a human-readable source representation. Useful for debugging or inspecting generated bytecode.

```javascript
fn add(a, b) { return a + b; }
println(decompile(add));
```

## core:math — Mathematics

```javascript
// Named imports
import { sqrt, pow, sin, cos, pi, e } from "core:math";

// Wildcard — module bound as `math`
import "core:math";
println(math.sqrt(16)); // 4
```

---

### Single-argument functions

Each accepts one `num` argument and returns a `num`.

| Function | Description |
|---|---|
| `abs(x)` | Absolute value |
| `acos(x)` | Arc cosine (radians) |
| `asin(x)` | Arc sine (radians) |
| `atan(x)` | Arc tangent (radians) |
| `ceil(x)` | Round up to nearest integer |
| `cos(x)` | Cosine (radians) |
| `cosh(x)` | Hyperbolic cosine |
| `exp(x)` | *e*^x |
| `floor(x)` | Round down to nearest integer |
| `log(x)` | Natural logarithm |
| `log10(x)` | Base-10 logarithm |
| `round(x)` | Round to nearest integer |
| `sin(x)` | Sine (radians) |
| `sinh(x)` | Hyperbolic sine |
| `sqrt(x)` | Square root |
| `tan(x)` | Tangent (radians) |
| `tanh(x)` | Hyperbolic tangent |

---

### Two-argument functions

| Function | Description |
|---|---|
| `atan2(y, x)` | Arc tangent of y/x (full quadrant) |
| `hypot(x, y)` | √(x² + y²) |
| `max(a, b)` | Larger of two values |
| `min(a, b)` | Smaller of two values |
| `pow(base, exp)` | base^exp |

---

### Constants

| Name | Value |
|---|---|
| `pi` | `3.14159265358979323846` |
| `e` | `2.71828182845904523536` |

```javascript
import { sin, cos, sqrt, pow, pi, e } from "core:math";

println(sqrt(2));       // 1.4142135623730951
println(pow(2, 10));    // 1024
println(sin(pi / 2));   // 1
println(e);             // 2.718281828459045
```

## core:os — Operating System Utilities

```javascript
import { getCwd, getPid, getUser, getType, system } from "core:os";
```

---

### getCwd

**Signature:** `getCwd() → string`

Returns the current working directory as a string.

```javascript
println(getCwd()); // /home/alice/projects
```

---

### getPid

**Signature:** `getPid() → int`

Returns the process ID of the running interpreter.

```javascript
println(getPid()); // 12345
```

---

### getUser

**Signature:** `getUser() → string`

Returns the current OS username. Falls back to the `USER` environment variable on headless Linux environments.

```javascript
println(getUser()); // alice
```

---

### getType

**Signature:** `getType() → string`

Returns a string identifying the host platform: `"win32"`, `"mac"`, `"linux"`, or `"unknown"`.

```javascript
if (getType() == "linux") {
    println("Running on Linux");
}
```

---

### system

**Signature:** `system(cmd: string) → int`

Executes `cmd` in the system shell (equivalent to C `system()`). Returns the exit status code.

{: .warning }
Never pass untrusted user input directly to `system()`. Validate and sanitise all inputs to prevent command injection.

```javascript
const code = system("ls -la");
println("exit:", code);
```

## core:Array — Array Class

```javascript
import { Array } from "core:Array";
```

{: .note }
Array methods (`push`, `pop`, `length`, `each`, `keep`) are available on every array literal without an explicit import. Import `core:Array` only when you need the class descriptor itself — e.g. to add static helper methods at runtime.

---

### push

**Signature:** `array.push(value)`

Appends `value` to the end of the array. Returns `null`.

```javascript
const arr = [1, 2];
arr.push(3);
println(arr); // [1, 2, 3]
```

---

### pop

**Signature:** `array.pop() → value`

Removes and returns the last element. Throws an error if the array is empty.

```javascript
const last = arr.pop();
println(last); // 3
println(arr);  // [1, 2]
```

---

### length

**Signature:** `array.length() → int`

Returns the number of elements in the array.

```javascript
println([10, 20, 30].length()); // 3
```

---

### each

**Signature:** `array.each(callback(index, element)) → array`

Calls `callback(index, element)` for every element and returns a new array containing each return value. Analogous to `Array.prototype.map` in JavaScript.

```javascript
const nums    = [1, 2, 3, 4, 5];
const doubled = nums.each(fn(i, e) { return e * 2; });
println(doubled); // [2, 4, 6, 8, 10]

// Vararg functions receive (index, element)
nums.each(println);
// 0 1
// 1 2
// 2 3 ...
```

---

### keep

**Signature:** `array.keep(callback(index, element)) → array`

Returns a new array containing only the elements for which `callback` returns a truthy value. Analogous to `Array.prototype.filter`.

```javascript
const evens = nums.keep(fn(i, e) { return e % 2 == 0; });
println(evens); // [2, 4]
```

---

### Adding static helpers at runtime

```javascript
import { Array } from "core:Array";

Array.sum = fn(arr) {
    local total = 0;
    arr.each(fn(i, e) { total += e; });
    return total;
};

println(Array.sum([1, 2, 3, 4, 5])); // 15
```

## core:Date — Date and Time

```javascript
import { Date } from "core:Date";
// Or wildcard:
import "core:Date";
```

---

### Constructor

| Form | Description |
|---|---|
| `new Date()` | Current date and time |
| `new Date(ms: number)` | Unix timestamp in **milliseconds** |
| `new Date(dateStr: string)` | Parse a date string |
| `new Date(year, month, [day, h, m, s, ms])` | Component form |

Supported date string formats: `YYYY-MM-DD`, `YYYY-MM-DD HH:mm:ss`, `YYYY-MM-DDTHH:mm:ss`, `YYYY/MM/DD HH:mm:ss`.

{: .note }
`month` is **0-based** (January = 0, December = 11), consistent with JavaScript's `Date`.

```javascript
const now = new Date();
println(now.toString()); // e.g. Fri Apr 04 2026 14:30:00

const d1 = new Date("2023-12-25");
println(d1.getFullYear()); // 2023
println(d1.getMonth());    // 11  (0-based)
println(d1.getDate());     // 25

// year=2024, month=Jan(0), day=1, 12:30:45
const d2 = new Date(2024, 0, 1, 12, 30, 45);

// Unix timestamp (milliseconds)
const d3 = new Date(1705449600000);
```

---

### Instance getters

| Method | Returns | Notes |
|---|---|---|
| `getFullYear()` | `int` | 4-digit year (e.g. 2026) |
| `getMonth()` | `int` | Month 0–11 (0 = January) |
| `getDate()` | `int` | Day of month 1–31 |
| `getDay()` | `int` | Day of week 0–6 (0 = Sunday) |
| `getHours()` | `int` | Hours 0–23 |
| `getMinutes()` | `int` | Minutes 0–59 |
| `getSeconds()` | `int` | Seconds 0–59 |

```javascript
const d = new Date("2026-04-04T14:30:00");
println(d.getFullYear()); // 2026
println(d.getMonth());    // 3   (April = index 3)
println(d.getDate());     // 4
println(d.getDay());      // 6   (Saturday)
println(d.getHours());    // 14
println(d.getMinutes());  // 30
println(d.getSeconds());  // 0
```

---

### getTime

**Signature:** `date.getTime() → num`

Returns the internal Unix timestamp in **milliseconds**.

```javascript
println(new Date().getTime()); // e.g. 1743778200000
```

---

### toString

**Signature:** `date.toString() → string`

Returns a human-readable string, e.g. `"Sat Apr 04 2026 14:30:00"`.

```javascript
println(new Date().toString());
```

## core:Promise — Promises

```javascript
import { Promise } from "core:Promise";
```

Promises are created **implicitly** by calling any `async` function. You rarely need to construct them manually. The two instance methods below form the chaining API.

---

### then

**Signature:** `promise.then(callback(value)) → Promise`

Registers a callback to run when the promise resolves. The callback receives the resolved value and its return value becomes the resolved value of the new promise returned by `then`, enabling chaining.

{: .note }
The callback must accept exactly **1 argument** (or use a vararg signature). A wrong arity produces a runtime error.

```javascript
fn getData() async { return 42; }

getData()
    .then(fn(v) {
        println("value:", v);  // value: 42
        return v * 2;
    })
    .then(fn(v) {
        println("doubled:", v); // doubled: 84
    });
```

---

### error

**Signature:** `promise.error(callback(err)) → Promise`

Registers a callback to run if the promise (or any preceding promise in the chain) is **rejected**. The callback receives the error value.

```javascript
fn mayFail() async {
    return somethingRisky();
}

mayFail()
    .then(fn(v) { println("Got:", v); })
    .error(fn(e) { println("Error:", e); });
```

---

### Full example

```javascript
import { println } from "core:io";

fn step1() async { return "hello"; }
fn step2(s) async { return s + " world"; }

fn pipeline() async {
    const s = await step1();
    return await step2(s);
}

pipeline()
    .then(fn(result) {
        println(result); // hello world
    })
    .error(fn(e) {
        println("Failed:", e);
    });
```
